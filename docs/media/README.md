# Demonstration media

Keep the repository itself light. Attach the final 8–15 second MP4 demonstration
to the matching GitHub Release and link it from the README.

The best short demo will show:

1. Power-on startup sequence
2. One fast page change
3. A temperature adjustment
4. The animated fan page
5. A physical press or long press

Use a tripod or fixed phone position, a clean background and locked exposure so
the AMOLED is readable. Avoid long unedited clips and screen recordings of the
Arduino IDE.
