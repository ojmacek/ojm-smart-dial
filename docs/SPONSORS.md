# Project support and disclosure

The following companies have provided hardware or workshop tools for the Smart
Dial project. Support is acknowledged here so the relationship is clear without
turning the main project page into an advertisement.

## Waveshare

Waveshare provided the ESP32-S3-Touch-AMOLED-1.32 module used as the controller
and display in the prototype. It is the core development board used by the
current firmware.

## Miniware

Miniware provided a TS101 Go Kit used for electronics and prototype assembly.

## Fanttik

Fanttik provided an E1 Max precision electric screwdriver used during assembly.

## iFixit

iFixit provided a FixMat and Manta Driver Kit used during prototype work.

## KORADEM

KORADEM has confirmed support with a KA3005PS bench power supply. Shipment and
tracking are still pending, so this supply has not been used for the version
currently shown in the repository. This note should be updated after delivery.

## Independence

Support consisted of products or tools. No sponsor controlled the design,
firmware, test results, bachelor-project conclusions or the wording of this
repository. Unless stated otherwise, the repository is not a product review and
does not contain affiliate links.

Brand logos are not included. They should only be added if the relevant company
has supplied approved assets or has explicitly permitted their use.
