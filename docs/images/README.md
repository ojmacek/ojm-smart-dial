# Image guide

Keep this directory curated. A strong public repository needs a few useful
images, not every photo taken during development.

Recommended final set:

1. `hero.jpg` — assembled prototype on a clean, neutral background
2. `ui-preview.png` — interface overview
3. `mechanism.jpg` — geared ring and encoder mechanism
4. `cad-assembly.png` — clean Fusion 360 assembly view
5. `rear-view.jpg` — mounting and cable routing

Use descriptive lower-case names, crop away unrelated desk clutter and remove
location or device metadata before publishing. A width around 1600–2000 pixels
is enough for README photographs. Prefer JPEG for photographs and PNG for UI or
CAD screenshots.

After a good assembled photo exists, replace the current UI strip near the top
of the main README with `hero.jpg` and move the UI strip farther down.
