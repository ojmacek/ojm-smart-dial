# Changelog

This file records public project milestones. Small work-in-progress saves stay
in Git history and do not need their own version number.

## [0.1.0-poc] - 2026-08-02

First public proof-of-concept release.

### Added

- Four-page automotive control interface
- Temperature, fan, airflow and seat-heating interactions
- Encoder press and long-press input
- Partial RGB565 display updates and TE synchronization
- Clean OJM Systems startup sequence
- DINish display font subset
- Initial hardware, wiring and sponsor documentation

### Known limitations

- The final controlled system has not yet been selected
- CAD and printable exports will be added after the latest print is validated
- The logo source file must currently be copied from the local project archive
