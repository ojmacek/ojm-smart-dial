# Hardware files

This directory is reserved for the latest validated mechanical files.

Use `exports/` for files intended for printing or exchange:

- `.3mf` for a ready-to-slice multi-part project
- `.step` for editable neutral CAD geometry
- `.stl` only when a mesh export is specifically useful

Do not publish every Fusion 360 save or failed print. Keep the editable Fusion
source and earlier experiments in the local project archive until the design is
validated and publication has been agreed with the project supervisor.

When the next print fits correctly, use clear names such as:

```text
SmartDial_Base_v0.1.step
SmartDial_RotatingRing_v0.1.step
SmartDial_UpperCover_v0.1.step
SmartDial_PrintSet_v0.1.3mf
```
